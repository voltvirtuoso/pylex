# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Pylex. Users should upgrade before reporting an issue against an older release.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub’s private vulnerability reporting for [voltvirtuoso/pylex](https://github.com/voltvirtuoso/pylex/security/advisories/new) when available. If private reporting is unavailable, contact the maintainer through the GitHub profile and include the affected version, a clear description, reproduction steps, and any relevant logs without including secrets or private documents.

Please allow reasonable time for investigation and coordinated disclosure. Do not upload confidential documents or credentials to issues, pull requests, or public discussions.
